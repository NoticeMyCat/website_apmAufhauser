# APM Aufhauser design system

Calm editorial presentation for Salzburg practice visitors. Preserve the owner's language, photographs, original logo, 90 € price and single-line hero name. Variance 5 / motion 3 / density 4.

One portrait with its own Yin-Yang artwork forms the hero. No second symbol, synthetic portrait, image inversion or ghosted face. Wide heading, tightly grouped introduction, authentic image; mobile naturally stacks. One brief image reveal on first load, disabled with reduced motion. All text remains visible without JavaScript.

Important anatomical and explanatory diagrams may use dedicated desktop, tablet and mobile artwork when each viewport needs a different composition. Always preserve the complete diagram with contain-only rendering; never overlay text or other imagery on its anatomy.

Warm ivory / mauve / charcoal palette with a consistently bright presentation. CSS semantic tokens control every surface. The site does not switch with the device color scheme. Original transparent LOGO.png from the source repository is the navigation mark. No white tile or glow.

Geist is retained as a locally served functional typeface for consistency with the established website and legible German text. Display weight 500; tracking never below -.04em. Responsive gutters, 1160px content width, 68ch reading measure. Thin rules and spacing organise long-form content; avoid repetitive cards. Buttons and menu targets >=44px.

Hero title remains one line at normal text settings from 320px. At text enlargement, accessibility reflow wins. All paragraphs remain >=16px. Photography is never inverted in dark mode.
